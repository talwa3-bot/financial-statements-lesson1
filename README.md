# ניתוח דוחות כספיים – שיעור 1

אתר המשחקים של השיעור הראשון, ארבעה משחקים:

1. משחק 1: שבץ את המאזן (`games/02-maazan.html`)
2. משחק 2: רווחיות, דוח רווח והפסד (`games/03-rivchi.html`)
3. משחק 3: תזרים מזומנים (`games/05-tazrim.html`), גרסה סטטית של משחק "אופק" מחבילת cashflow-game-source
4. משחק 4: החלטה נכונה?, משחק ההחלטות העסקיות המסכם (`games/04-hachlata.html`)

האתר באוויר: https://talwa3-bot.github.io/financial-statements-lesson1/

- הקבצים בענף `main` (index.html בשורש).
- GitHub Pages מגיש את הענף `gh-pages`, שמתעדכן אוטומטית מ-`main` בכל שינוי (`.github/workflows/publish.yml`).
- האתר סטטי לגמרי: אין שרת, אין מסד נתונים ואין מצב משותף. הניקוד נשמר בדפדפן של כל משתתף (localStorage), והתוצאה נשלחת דרך קישור אישי לטופס Google.
